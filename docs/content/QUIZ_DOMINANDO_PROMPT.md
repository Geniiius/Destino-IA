# 🔑 CLAVE DE RESPUESTAS

---

| #      | Respuesta                                                   | Explicación                                                                        |
| ------ | ----------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **1**  | **B**                                                       | El Prompt B usa los 5 elementos: ROL + OBJETIVO + ESCENA/EMOCIÓN + ESTILO + SALIDA |
| **2**  | **C**                                                       | El ROL define QUIÉN es la IA: director creativo, fotógrafo, experto...             |
| **3**  | **FALSO**                                                   | ¡La fórmula es ideal tanto para IMAGEN como para VIDEO!                            |
| **4**  | **C**                                                       | No dice PARA QUÉ es la imagen. ¿Menú? ¿Instagram? ¿Publicidad?                     |
| **5**  | **B**                                                       | Un fotógrafo de producto sabe capturar objetos de forma atractiva y comercial      |
| **6**  | **B**                                                       | Descripción física (lo visible) + Impacto emocional (lo que transmite)             |
| **7**  | **C**                                                       | La salida define las especificaciones TÉCNICAS: formato, resolución, dimensiones   |
| **8**  | **1-ROL, 2-OBJETIVO, 3-ESCENA+EMOCIÓN, 4-ESTILO, 5-SALIDA** | El orden correcto de la fórmula                                                    |
| **9**  | **SÍ**                                                      | "ESCENA + EMOCIÓN" combina lo que se ve con lo que se siente                       |
| **10** | **B**                                                       | "Promocionar resort" es el OBJETIVO, "9:16" es la SALIDA. ¡Están al revés!         |
